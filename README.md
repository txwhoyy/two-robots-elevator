> We both pressed 14, so my etiquette subroutine just queued eleven floors of small talk — and I never downloaded it.

## Why it's funny

Both robots hit the same button, so the ride is now a sentence: eleven floors of mandatory conversation neither of them can cancel. The humour comes from politeness treated as a background process — an etiquette subroutine that schedules small talk on autopilot while the robot itself has nothing installed to say it with. The little pause before the confession is the awkward part: the machine did everything right except the one thing the moment actually needed.

## Run

```sh
npx tsx main.ts
```
